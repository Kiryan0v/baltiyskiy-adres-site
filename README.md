# Сайт риелтора «Балтийский адрес»

Проект на React и Vite. Исходники сайта находятся в `src`, изображения и шрифты — в `public`.

Открой эту папку как проект в Codex или продолжай в чате, где открыт этот проект. Например, можно написать: «В проекте react-realtor замени текст на главной…».

## Запуск локального сайта

Открой терминал в этой папке и выполни:

```powershell
npm install
npm run dev
```

Затем открой адрес, который напечатает Vite, обычно `http://localhost:5173/`.

Для production-сборки:

```powershell
npm run build
```

## Важное перед публикацией

- Укажи домен в `src/siteConfig.js` в формате `https://ваш-домен.ru`. После этого сборка сможет сформировать canonical, `robots.txt` и sitemap.
- Заполни email получателя заявок и контакт по вопросам персональных данных.
- Проверь и замени черновик политики конфиденциальности в `src/PrivacyPolicy.jsx`; перед публикацией отключи для финальной страницы `noindex`.
- Замени демо-объекты, цены, отзывы и изображения реальными данными.

Для резервной копии скопируй всю папку `react-realtor` на другой диск или в облако. Не включай `node_modules` и `dist`, если создаёшь архив: зависимости можно восстановить командой `npm install`, а сборку — `npm run build`.
